# Ch10. 클래스 · 객체 · 컬렉션 종합 예제

지금까지 학습한 비트 연산, 메서드, 예외 처리에 클래스/객체와 컬렉션(`Map`, `List`)을 더해 하나의 프로그램으로 만든 종합 예제입니다.

## 학습 주제
- 클래스 정의와 인스턴스 메서드 (`public void`, `public byte`)
- 인스턴스 메서드를 통한 비트 세팅 (`setFlagBit`, `setBitOne`)
- `throws Exception` 을 활용한 예외 선언
- `try / catch` 로 잘못된 입력값(숫자 외) 처리
- `HashMap<String, Object>` 과 `ArrayList<Integer>` 컬렉션 활용
- 반복 입력 루프와 종료 조건 처리(`-1` 입력 시 종료)

## 예제 코드

| 파일 | 설명 |
| --- | --- |
| [`BitSet.java`](BitSet.java) | 사용자가 입력한 위치(0~7)의 비트를 1로 세팅하고, 매 반복마다 현재 비트 상태를 출력. 종료 시점에 세팅 횟수·입력 이력·최종 상태를 `Map`/`List` 로 정리해 출력합니다. |

## 동작 흐름
1. 8비트 `flag` 변수를 `0b00000000` 으로 초기화.
2. 콘솔에서 비트 위치(0~7)를 입력 받음.
3. 입력값이 `-1` 이면 루프 종료, 범위 밖이면 안내 후 재입력.
4. `setFlagBit()` 으로 해당 비트를 1 로 세팅하고 현재 상태를 이진수로 출력.
5. 종료 시 총 세팅 횟수, 입력 인덱스 리스트, 결과 맵을 출력.
