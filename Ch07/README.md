# Ch07. 반복문 (for · while · do-while)

`for`, `while`, `do-while` 반복문과 중첩 반복문을 활용한 다양한 예제를 학습합니다.

## 학습 주제
- `for` 문 기본 구조와 누적/카운트
- `while` / `do-while` 의 차이
- 중첩 반복문 (구구단, 좌표 출력)
- 반복문 안에서 `break` 를 이용한 조기 종료
- 단순한 알고리즘적 문제 풀이 (배수 합, 자릿수 탐색)

## 예제 코드

| 파일 | 설명 |
| --- | --- |
| [`ByTimes5.java`](ByTimes5.java) | `for` 문으로 5단 구구단 출력. |
| [`For1_9.java`](For1_9.java) | 중첩 `for` 문으로 2~9단 구구단 전체 출력. |
| [`PartialByTimes.java`](PartialByTimes.java) | 짝수 단(2,4,6,8단)만 출력하는 중첩 반복문. |
| [`SumTo100.java`](SumTo100.java) | `while` 로 1~99 합계 계산. |
| [`Multiple1To100.java`](Multiple1To100.java) | 1~10 까지의 곱(10!) 계산. |
| [`Multiple2And7.java`](Multiple2And7.java) | 1000 이하의 수 중 2와 7의 공배수를 모두 출력하고 합산. |
| [`Num5_7.java`](Num5_7.java) | 1~100 중 5와 7의 공배수를 찾으면 즉시 `break`. |
