# Ch02. Java 입문 & 출력문

자바 프로그램의 기본 구조와 `System.out.println()`을 활용한 출력 방법을 학습합니다.

## 학습 주제
- `public class` 와 `main` 메서드 구조
- `package` 선언과 클래스 파일 배치
- `System.out.println()` 을 이용한 표준 출력
- 문자열, 정수, 실수 출력 및 `+` 연산자를 이용한 문자열 결합

## 예제 코드

| 파일 | 설명 |
| --- | --- |
| [`FirstJavaProgram.java`](FirstJavaProgram.java) | 최초의 자바 프로그램. "FirstJavaProgram" / "하이 자바!" 문자열을 출력합니다. |
| [`FirstJavaProgram_01.java`](FirstJavaProgram_01.java) | `package` 선언 없이 default package 에서 실행되는 동일한 예제. |
| [`SystemOutPrintln.java`](SystemOutPrintln.java) | 정수·실수·문자열을 다양한 형태로 결합해 출력하는 예제. |
| [`SystemOutPrintln_01.java`](SystemOutPrintln_01.java) | 클래스명을 `SystemOutPrintln_Copy` 로 바꾼 default package 예제. |

## 실행 방법
```bash
javac Ch02/FirstJavaProgram.java
java Ch02.FirstJavaProgram
```
