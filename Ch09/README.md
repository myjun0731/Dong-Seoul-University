# Ch09. 메서드(Method)

메서드의 정의, 매개변수, 반환값, 그리고 메서드를 활용한 작은 프로그램(숫자 맞추기 게임)을 학습합니다.

## 학습 주제
- `public static` 메서드 정의와 호출
- 매개변수(parameter) 1개 / 2개 / 0개
- 반환값(`return`)과 반환 타입(`int`, `double`, `void`)
- `java.util.Random` 을 이용한 난수 생성
- 사용자 입력과 메서드를 결합한 응용 예제

## 예제 코드

| 파일 | 설명 |
| --- | --- |
| [`MethodDef.java`](MethodDef.java) | 가장 단순한 형태의 메서드 정의/호출 예제(`void` + 1 parameter). |
| [`Method2Param.java`](Method2Param.java) | 매개변수가 2개인 메서드, 매개변수가 없는 메서드 함께 활용. |
| [`MethodReturns.java`](MethodReturns.java) | `int` / `double` 반환값을 갖는 메서드 정의. |
| [`ByTimes.java`](ByTimes.java) | 사용자가 입력한 단(`n`)의 구구단을 출력하는 메서드. |
| [`SimpleOperation.java`](SimpleOperation.java) | 두 정수에 대한 사칙연산 결과를 배열에 저장하는 메서드. |
| [`Number2Digits.java`](Number2Digits.java) | `Random` 으로 생성한 두 자릿수를 맞추는 업/다운 게임. |
