# Ch03. 변수와 자료형

자바의 기본 자료형, 변수 선언/초기화, 상수, 형 변환(promotion), 이스케이프 시퀀스를 학습합니다.

## 학습 주제
- 변수 선언과 초기화 (`int`, `double`, `short`, `char`, `boolean`)
- `final` 키워드를 이용한 상수 선언
- 문자형(`char`)과 유니코드 (10진수 / 16진수 표현)
- 이스케이프 시퀀스 (`\b`, `\t`, `\n`, `\r`)
- 산술 연산 시 자동 형 변환(promotion) 과 명시적 캐스팅

## 예제 코드

| 파일 | 설명 |
| --- | --- |
| [`UseVariable.java`](UseVariable.java) | 변수 선언/대입/연산 후 출력하는 기본 예제. |
| [`VariableDecl.java`](VariableDecl.java) | `double` 변수 두 개를 선언·초기화·연산하는 예제. |
| [`Constants.java`](Constants.java) | `final` 키워드로 상수를 선언하고 활용하는 예제. |

| [`EscapeSequences.java`](EscapeSequences.java) | 백스페이스/탭/개행/캐리지리턴 등 이스케이프 시퀀스 출력. |
| [`OperatePromotion.java`](OperatePromotion.java) | `short` 변수 연산 시 자동 형 변환과 명시적 캐스팅. |
