# Ch05. 연산자

자바의 산술/관계/논리/복합 대입 연산자와 단축 평가(Short-Circuit Evaluation)를 학습합니다.

## 학습 주제
- 산술 연산자 (`+`, `-`, `*`, `/`, `%`)
- 관계 연산자 (`>=`, `<=`, `==`, `!=`)
- 논리 연산자 (`&&`, `||`, `!`)
- 복합 대입 연산자 (`+=`, `*=` …) 와 형 변환
- 단축 평가 (`&&`, `||` 의 조건에 따른 평가 생략)

## 예제 코드

| 파일 | 설명 |
| --- | --- |
| [`ArithOp.java`](ArithOp.java) | 두 정수에 대한 +, -, *, /, % 연산 결과 출력. |
| [`RelationalOp.java`](RelationalOp.java) | 관계 연산자의 결과(true/false) 출력. |
| [`LogicalOp.java`](LogicalOp.java) | AND/OR/NOT 논리 연산 활용 (배수 확인, 범위 확인). |
| [`CompAssignOp.java`](CompAssignOp.java) | 복합 대입 연산자 사용 시 발생하는 자동 형 변환 비교. |
| [`SCE.java`](SCE.java) | 단축 평가(Short-Circuit Evaluation)로 인해 우측 피연산자가 평가되지 않는 케이스 확인. |
